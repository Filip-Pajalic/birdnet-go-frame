# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment and
personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/Filip-Pajalic). Reports are handled confidentially.
